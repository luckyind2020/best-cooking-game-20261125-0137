Ember Ladle — Sizzle & Serve: a complete original 2D cooking game that plays offline in a desktop browser. Take tickets from the order board, chop tomatoes, lettuce and onions, grill patties golden, stack dishes on plates and serve them before the timers run out. Orders arrive faster as the lunch rush builds, combos reward quick serves, and a burnt patty goes straight in the bin.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — move with WASD or arrow keys, press E (or click a station) to pick up, chop, grill, plate and serve. Q bins what you are holding, P pauses, M mutes, R restarts the day.
